# NFL Stats Service

FastAPI backend for retrieving NFL player data using the Sleeper API. This is the initial skeleton for a lightweight NFL stats microservice.

## Setup

Create and activate a virtual environment:

python -m venv venv
source venv/Scripts/activate

Install dependencies:

pip install -r requirements.txt

Run the server:

uvicorn app:app --reload
